| Task | Classification | Rationale |
| :--- | :--- | :--- |
| 1. Writing boilerplate code (e.g., component setup, basic routing) | Fully Automate | AI is highly reliable at generating standard boilerplate with clear instructions, saving time. |
| 2. Formatting and linting code | Fully Automate | Pre-configured tools and AI can handle formatting without requiring human decision-making. |
| 3. Generating unit tests for basic functions | Fully Automate | AI excels at covering standard edge cases and writing repetitive test structures. |

| 8. Reading and understanding complex legacy code | Collaborate with AI | AI can explain snippets, while I piece together the broader architectural context. |
| 9. Planning architecture for a new app/feature | Collaborate with AI | AI can act as a sounding board for pros/cons, but the final architectural decisions require my judgment. |
| 10. Learning a new programming language/framework | Collaborate with AI | AI acts as a pair-programmer and tutor, but I must actively engage to actually learn. |
| 11. Brainstorming project ideas or UI designs | Collaborate with AI | AI provides diverse variations and inspiration that I then refine and select from. |
| 12. Reviewing peer pull requests | Collaborate with AI | AI can spot syntax issues or smells, but I need to assess the logic and business requirements. |
| 13. High-level strategic decision making | Just me | Requires deep understanding of business goals, user empathy, and long-term vision that AI lacks. |
| 14. Attending team meetings/syncs | Just me | Human connection, non-verbal cues, and real-time collaboration are essential here. |
| 15. Personal networking and relationship building | Just me | Building genuine trust and rapport with peers and mentors is a uniquely human task. |
